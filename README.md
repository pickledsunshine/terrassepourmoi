# Terrace Finder

Build a minimal web app called Terrasse? where I enter an area, date, time window and party size, and the app estimates my probability of finding a terrace seat in that area. The interface should be extremely simple and cute. The complexity should live in the prediction engine, not the UI. Start with realistic mock restaurant/weather data so we can test the experience before connecting APIs
